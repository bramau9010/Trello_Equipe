# Dashboard de Acompanhamento da Equipe no Trello

Este projeto cria visualizações customizadas para o acompanhamento de performance da minha equipe, utilizando dados de um quadro do Trello.

Para implementar este relatório, automatizei a conexão com a API do Trello, realizei o tratamento dos dados e, por fim, automatizei a atualização e o deploy contínuo via GitHub.
